# 2026 高齡照護創新研討會

本資料夾為 GitHub Pages 靜態網站版本。

## 發布方式

1. 在 `MIRDC-WFevents1` 建立公開 repository：`aging-care-innovation-forum-2026`
2. 將本資料夾內的全部檔案上傳至 repository 根目錄
3. 前往 **Settings → Pages**
4. Source 選擇 **Deploy from a branch**
5. Branch 選擇 **main**，資料夾選擇 **/(root)**

預計網址：

`https://mirdc-wfevents1.github.io/aging-care-innovation-forum-2026/`

## 主要檔案

- `index.html`：網站內容
- `styles.css`：網站版面與手機版樣式
- `assets/`：活動海報、講者照片及辦理單位 Logo
